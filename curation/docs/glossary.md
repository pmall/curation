# Glossary

The terms of the curation, one meaning each. The Drakkar database's terms (publication, run, state, curation pass, description, mapping…) are defined in its `glossary.md`, and used here with that meaning.

| Term | Meaning |
| -- | -- |
| Batch | An orchestrated curation of publications, by the `curate` skill: one curator agent each, merged into one set of files and committed together after the user's go. Never "run". |
