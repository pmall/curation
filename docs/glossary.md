# Glossary

One meaning per word, used everywhere: docs, code, reports and conversations. When a schema name says otherwise, the schema name is legacy and this glossary wins. Points marked **to confirm** are open.

## Publications and their curation

| Term          | Meaning                                                                                                                                                                                                                       |
| ------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Publication   | A PubMed record, identified by its PMID (`publications`). Never "paper".                                                                                                                                                      |
| Run           | A batch of PMIDs returned by the PubMed query (`runs`), of type vh or hh. Named by a number.                                                                                                                                  |
| vh, hh        | Virus–human and human–human. A vh run looks for virus–human interactions, an hh run for human–human ones. hh is frozen history: no new curation, but its invalid data is fixed.                                               |
| Association   | A publication in a run (`associations`). It carries the state and the note. A publication can be in a vh run and an hh run: two associations.                                                                                 |
| State         | The curation state of an association: `pending` (not pre-curated), `selected` (kept at pre-curation, curation in progress), `discarded` (rejected at pre-curation), `curated` (full text read, with or without descriptions). |
| Pre-curation  | The decision `selected` or `discarded`, from the title and abstract.                                                                                                                                                          |
| Curation pass | Reading the full text of a selected publication and recording its descriptions. Ends with the state `curated`. Claude's last pass is dated by `associations.ai_pass_at`.                                                      |
| Note          | The free text of an association (`associations.annotation`), explaining the curation decisions. It never holds maintenance information.                                                                                       |

## Proteins

| Term               | Meaning                                                                                                                                                                                                                                              |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Protein            | A UniProt entry, identified by its accession (e.g. `P04439`). Human or viral (`proteins.type` `h` or `v`).                                                                                                                                           |
| Release            | A UniProt release (e.g. `2021_02`). The latest one loaded in Drakkar is the current release.                                                                                                                                                         |
| Snapshot           | A protein as it is in a release: one row of `proteins` (sequences, gene name, taxon). A protein has snapshots, never versions. The schema names `proteins.version` (the release a snapshot first appeared in) and `proteins_versions` are legacy.    |
| Current snapshot   | The snapshot of a protein in the current release (listed in `proteins_versions`). At most one per protein.                                                                                                                                           |
| Obsolete snapshot  | A snapshot that is not current: the protein changed since, or was deleted from UniProt.                                                                                                                                                              |
| Canonical sequence | The reference sequence of a snapshot, stored under its accession in `proteins.sequences`. Coordinates are positions on it. Its length is the length of the protein.                                                                                  |
| Isoform            | Another sequence of the same snapshot, stored under its own accession (e.g. `P04439-2`) in `proteins.sequences`.                                                                                                                                     |
| Gene name          | The gene name of a human snapshot (`proteins.name`), e.g. `CCN1`.                                                                                                                                                                                    |
| Species            | The NCBI taxon of a protein (`proteins.ncbi_taxon_id`), which must exist in the taxonomy (`taxon`). For a viral protein: the virus.                                                                                                                  |
| Polyprotein        | A viral protein cleaved into several mature proteins.                                                                                                                                                                                                |
| Mature protein     | A part of a polyprotein, identified by the polyprotein accession and coordinates (e.g. DENV1 NS5 = `B5AGU1[2494-3392]`). Its right coordinates are those of the polyprotein's chain features in UniProt, the source of truth [confirmed 2026-10-06]. |

## Descriptions

| Term                 | Meaning                                                                                                                                                                                                                                                                                                                                 |
| -------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Coordinates          | The start and stop of an interactor on the canonical sequence of its snapshot, 1-based and inclusive.                                                                                                                                                                                                                                   |
| Interactor           | (accession, start, stop), reached through the snapshot it points to.                                                                                                                                                                                                                                                                    |
| Human interactor     | Always the full protein: coordinates 1 to the length. Named by its gene name (`name1`; in hh, `name2` too).                                                                                                                                                                                                                             |
| Viral interactor     | A full viral protein or a mature protein (`protein2_id`, `start2`, `stop2` in vh). Named by its generic name (`name2`).                                                                                                                                                                                                                 |
| Generic name         | The standard name of a viral interactor (e.g. `NS1`), independent of how UniProt or the publication names it. One viral interactor has one generic name, and in one protein a generic name names one viral interactor: (accession, start, stop) ↔ (accession, generic name).                                                            |
| Method               | A PSI-MI interaction detection method (`methods`, e.g. `MI:0007`).                                                                                                                                                                                                                                                                      |
| Description          | One row of evidence: a publication × a method × a human interactor × a viral interactor (hh: two human interactors), with its mappings. This combination, (PMID, PSI-MI ID, interactor 1, interactor 2), is recorded once. Two mature proteins of the same polyprotein are two interactors, so two descriptions [confirmed 2026-10-06]. |
| Interaction          | A human interactor × a viral interactor, whatever the publication and the method. One interaction can have many descriptions: that is the point of curation.                                                                                                                                                                            |
| Mapping              | The sequence of an interaction domain on one side of a description (`mapping1` human, `mapping2` viral), as the publication gives it. It is never adapted to UniProt.                                                                                                                                                                   |
| Malformed mapping    | A mapping whose JSON structure or types are wrong (e.g. numbers stored as text), whatever its content. Fixed in place, not by a revision.                                                                                                                                                                                               |
| Occurrence           | Where a mapping is found: an isoform, a start and stop, and an identity. On the canonical sequence, positions are relative to the interactor's coordinates; on other isoforms, to the whole isoform. Stored with the mapping, computed by Claude.                                                                                       |
| Identity             | The share of identical residues between a mapping and its occurrence, over the alignment length. An occurrence must reach 96 %.                                                                                                                                                                                                         |
| Stable ID            | The permanent identifier of a description (`EY…` from the web interface, `CW…` from Claude). It never changes.                                                                                                                                                                                                                          |
| Version              | One state of a description: rows with the same stable ID, numbered 1, 2, 3… A version is always a description version, never a protein one.                                                                                                                                                                                             |
| Live                 | The version of a description that is in use (`deleted_at` null). At most one per stable ID.                                                                                                                                                                                                                                             |
| Revision             | Writing a new version of a description: the live version is deleted and the new one created at the same instant.                                                                                                                                                                                                                        |
| Removed description  | A stable ID whose last version is deleted, with no successor. Nothing is ever physically deleted.                                                                                                                                                                                                                                       |
| Obsolete description | A live description that points to an obsolete snapshot.                                                                                                                                                                                                                                                                                 |

## Checking and fixing

| Term        | Meaning                                                                                                                                                                             |
| ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Invariant   | A rule the data must follow, with an ID (`database.md` §4). It is checked against the snapshots a description points to, whether current or obsolete.                               |
| Violation   | A row that breaks an invariant, as reported by `drakkar-check`.                                                                                                                     |
| Problem     | A kind of invalid data, defined by its fix (what we change), not by the invariant that detects it.                                                                                  |
| Fix         | The correction of a problem, by a revision. A description that needs several fixes gets them in one revision. Exception: a malformed mapping is fixed in place, without a revision. |
| Fix job     | Correcting the invalid data. Never moves a description to another snapshot.                                                                                                         |
| Upgrade job | Loading a new UniProt release and moving obsolete descriptions to current snapshots. Never mixed with the fix job.                                                                  |
