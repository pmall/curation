# Poxviridae

Family conventions: a poxvirus protein is named by the ORF label UniProt gives it, in UniProt's spelling for that virus: vaccinia and variola drop the orientation letter because UniProt's protein names do (`E3`, `A46`, `C5`), the other genera keep the gene as written (`CPXV040`, `ORFV125`, `M013L`, `MC159L`, `EVM010`, `FPV039`, `CNPV058`, `DPV022`, `AMV263`). A protein whose UniProt name is a protein name the field uses keeps that name (`CrmA`, `CrmB`, `CrmD`, `CrmE`, `SPI-1`, `SPI-2`, `TK`, `M-T5`, `CP77`, `vBcl-2`). The OPG numbers are the pan-orthopoxvirus gene identifiers, kept only as synonyms.
