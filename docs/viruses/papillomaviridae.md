# Papillomaviridae

Family conventions: every protein takes the letter and number of its gene or ORF, exactly as UniProt writes it (`E1`, `E2`, `E4`, `E5`, `E5A`, `E5B`, `E6`, `E7`, `L1`, `L2`). Spliced products keep the UniProt name of the junction (`E8^E2C`). All species of the family use the same names; only the sequences differ.
