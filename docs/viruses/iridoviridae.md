# Iridoviridae

Family conventions: proteins are named by the ORF label UniProt gives them, in each virus's spelling: frog virus 3 and invertebrate iridescent virus 6 write it as a bare number plus orientation (`062L`, `077L`), the other viruses with the `ORF` prefix UniProt uses (`ORF29L`, `ORF103R`, `ORF158L`). None of these viruses has a protein name the field uses instead.
