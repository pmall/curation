# Rhabdoviridae

Family conventions: the one-letter gene names (`N`, `P`, `M`, `G`, `L`), the same in lyssaviruses, vesiculoviruses and the other genera.

## Rabies virus (*Lyssavirus rabies*, NCBI 11292)

| Generic name | Protein (UniProt name; gene) | Reference    | Length | Also called       |
| ------------ | ---------------------------- | ------------ | -----: | ----------------- |
| `N`          | Nucleoprotein; N             | P06025 1–450 |    450 | NP                |
| `P`          | Phosphoprotein; P            | P16286 1–297 |    297 | Protein M1        |
| `M`          | Matrix protein; M            | P16287 1–202 |    202 | Phosphoprotein M2 |
| `G`          | Glycoprotein; G              | P16288 1–524 |    524 | —                 |

Names: `N`, the gene name, not the UniProt short name `NP`, as the field writes it for rhabdoviruses. `G` covers the whole protein with its signal peptide, as used in Drakkar.
